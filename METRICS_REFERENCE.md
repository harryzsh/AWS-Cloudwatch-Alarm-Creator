## Tag-Based Alarms

Deployed via `cloudformation-tag-based-alarms.yaml`. Uses CloudWatch Metrics Insights SQL with tag filtering. All alarms use `_WARNING` suffix.

**Total: 9 alarms**  
**Parameters (all required):** `--tag-key`, `--tag-value`, `--sns-topic`  
**Naming:** `{TagValue}-{Service}-{Metric}_WARNING`  
**Actions:** AlarmActions + OKActions (notified on trigger and recovery)

### EC2 Instances

**Alarms:** 6  
**Namespace:** `AWS/EC2`

| Metric | Threshold | Operator | Description |
|--------|-----------|----------|-------------|
| CPUUtilization | 90% | > | 服务器CPU使用率超过90% |
| StatusCheckFailed_System | 1 | >= | EC2系统状态检查失败 |
| StatusCheckFailed | 1 | >= | EC2状态检查失败 |
| StatusCheckFailed_Instance | 1 | >= | EC2实例状态检查失败 |
| InstanceEBSThroughputExceededCheck | 1 | >= | EC2实例EBS吞吐量超过实例最大限制 (Nitro only) |
| InstanceEBSIOPSExceededCheck | 1 | >= | EC2实例EBS IOPS超过实例最大限制 (Nitro only) |

### NAT Gateway

**Alarms:** 1  
**Namespace:** `AWS/NATGateway`

| Metric | Threshold | Operator | Description |
|--------|-----------|----------|-------------|
| ErrorPortAllocation | 100 | > | NAT网关端口分配错误超过100次 |

### VPN

**Alarms:** 2  
**Namespace:** `AWS/VPN`

| Metric | Dimensions | Threshold | Operator | Description |
|--------|------------|-----------|----------|-------------|
| TunnelState (connection) | VpnId | 1 | < | VPN连接隧道状态异常 - 连接级别 |
| TunnelState (tunnel) | VpnId, TunnelIpAddress | 1 | < | VPN隧道状态异常 - 隧道级别 |

## Resource-Based Alarms

Configured in `alarm-config-resource-based.yaml`, generated by `resource_alarm_builder.py`. Creates dedicated alarms per discovered resource using stable hash-based CloudFormation logical IDs.

**Naming:** `{TagValue}-{Service}-{ResourceId}-{Metric}_WARNING`  
**Actions:** AlarmActions + OKActions (notified on trigger and recovery)

### EC2 (CWAgent)

**Alarms per instance:** 2  
**Namespace:** `CWAgent`  
**Primary Dimension:** InstanceId  
**Discovery:** Tagged EC2 instances via `describe_instances`, filtered by `list_metrics` to only include instances with active CWAgent data  
**Note:** CWAgent doesn't support tag-based Metrics Insights filtering — alarms are per-instance using SQL `WHERE InstanceId = '...'`

| Metric | Threshold | Operator | Description |
|--------|-----------|----------|-------------|
| mem_used_percent | 90% | > | EC2实例内存使用率超过90% |
| disk_used_percent | 90% | > | EC2实例磁盘使用率超过90% (worst mount point) |

Requires [CloudWatch Agent](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/Install-CloudWatch-Agent.html) installed on EC2 instances. Instances without CWAgent are automatically skipped during discovery.

### MSK (Kafka)

**Alarms per cluster:** 5  
**Namespace:** `AWS/Kafka`  
**Primary Dimension:** Cluster Name  
**Discovery:** Tagged MSK clusters via `list_clusters`

| Metric | Threshold | Operator | Description |
|--------|-----------|----------|-------------|
| MaxOffsetLag | 200,000 | > | Kafka消费者组最大偏移延迟 |
| CpuUser | 90% | > | Kafka Broker CPU用户空间使用率 |
| HeapMemoryAfterGC | 90% | > | Kafka Broker GC后堆内存使用百分比 |
| KafkaDataLogsDiskUsed | 75% | > | Kafka数据日志磁盘使用率 |
| ActiveControllerCount | 1 | < | Kafka活跃控制器数量 - 应始终为1 |

### ACM

**Alarms per certificate:** 1  
**Namespace:** `AWS/CertificateManager`  
**Primary Dimension:** CertificateArn  
**Discovery:** Tagged certificates via `list_certificates` (all key types)

| Metric | Threshold | Operator | Description |
|--------|-----------|----------|-------------|
| DaysToExpiry | 30 days | <= | ACM证书到期天数 - 证书即将过期 |

### Application Load Balancer (ALB)

**Alarms per load balancer:** 1  
**Namespace:** `AWS/ApplicationELB`  
**Primary Dimension:** LoadBalancer  
**Discovery:** Tagged ALBs via `describe_load_balancers` (Type=application)

| Metric | Threshold | Operator | Description |
|--------|-----------|----------|-------------|
| UnHealthyHostCount | 1 | >= | ALB后端不健康主机数量大于等于1 |

### Direct Connect

**Alarms per connection:** 3  
**Namespace:** `AWS/DX`  
**Primary Dimension:** ConnectionId  
**Discovery:** Tagged connections via `describe_connections` (ARN-based tag lookup)

| Metric | Threshold | Operator | Type | Description |
|--------|-----------|----------|------|-------------|
| ConnectionState | 1 | < | Standard | Direct Connect连接状态 - 连接断开 |
| IngressBandwidthPercent | 90% | > | Math | Direct Connect入站带宽使用百分比 |
| EgressBandwidthPercent | 90% | > | Math | Direct Connect出站带宽使用百分比 |

Math Expression: `m1/bandwidth*100`. Bandwidth auto-detected from `describe_connections`.

### EBS

**Alarms per volume:** 3  
**Namespace:** `AWS/EBS`  
**Primary Dimension:** VolumeId  
**Discovery:** Volumes attached to tagged EC2 instances via `describe_volumes`

| Metric | Threshold | Operator | Description |
|--------|-----------|----------|-------------|
| VolumeThroughputExceededCheck | 1 | >= | EBS卷吞吐量超过预置限制 (0=ok, 1=exceeded) |
| VolumeIOPSExceededCheck | 1 | >= | EBS卷IOPS超过预置限制 (0=ok, 1=exceeded) |
| VolumeStalledIOCheck | 1 | >= | EBS卷IO停滞检测 (0=ok, 1=stalled) |

| Setting | Value |
|---------|-------|
